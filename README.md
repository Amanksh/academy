# Mudra Dance Academy

Website for event discovery, class booking, schedules, and membership at Mudra Dance Academy.

## Pages

- **Events** — featured masterclass, category filters, trending classes
- **Classes** — style / level / instructor filters, class cards, Book now
- **Schedule** — date strip, daily sessions, session status
- **Membership** — XP, tiered INR plans, payment history

## Run locally

```bash
npm install
npm run dev
```
